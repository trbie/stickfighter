About

Tag-Team Takedown is a 2-D fighting game inspired by Street Fighter and developed in Unity. Players control two characters, a fast striker and a hard-hitting bruiser, and can switch between them at any time; if either one is defeated, the match ends. The game includes Normal mode (a single-round fight against one opponent) and Onslaught mode, where the Player fights three consecutive waves against an enemy that deals more damage each round. It also has a short interactive tutorial that covers movement, attacks, blocking, and character swapping. The first release is planned for PC and WebGL, with possible console ports later.
